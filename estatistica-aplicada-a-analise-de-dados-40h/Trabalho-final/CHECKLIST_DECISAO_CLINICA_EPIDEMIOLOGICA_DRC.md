# Checklist para decisão clínica e epidemiológica

**Objetivo:** decidir se existe base suficiente para uma coorte comparativa. Este checklist não autoriza análise de efetividade; ele apenas registra uma decisão de viabilidade.

| Decisão | Pergunta para a reunião | Resposta/decisão | Responsável |
|---|---|---|---|
| População | Quem é elegível antes do início do tratamento? |  | Nefrologista |
| Estratégias | Quais procedimentos representam hemodiálise e diálise peritoneal em cada competência? |  | Nefrologista + equipe de dados |
| Comparador | As duas modalidades são opções plausíveis para o mesmo perfil clínico? |  | Nefrologista + epidemiologista |
| Tempo zero | Qual evento observável marca o início comparável de cada estratégia? |  | Epidemiologista |
| Seguimento | Qual horizonte, censura e regra para troca de modalidade/transferência? |  | Epidemiologista |
| Desfecho | Qual fonte define óbito ou outro desfecho, com data e cobertura verificáveis? |  | Clínico + gestor da base |
| Confundimento | Quais covariáveis pré-tratamento são indispensáveis e estão disponíveis? |  | Epidemiologista |
| Vínculo | O identificador e as regras APAC permitem seguir a mesma pessoa sem ambiguidade? |  | Gestor da base |
| Ética e governança | Há base legal, autorização e proteção compatíveis com o vínculo necessário? |  | Responsável institucional |

## Regra de decisão

Avançar para uma coorte somente se todos os itens tiverem resposta documentada e fonte verificável. Se qualquer item central falhar, registrar “não estimável com as fontes atuais” e manter o estudo no escopo descritivo/ecológico.
